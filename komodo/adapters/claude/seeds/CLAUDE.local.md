# Personal overlay

Machine- or person-specific instructions that sit on top of the shared
`AGENTS.md` — never checked in, never synced. The installer copies this
template here once; edit the copy at `~/.claude/CLAUDE.local.md` freely
from then on, it is never overwritten again.

Loaded by every session via `CLAUDE.md`'s `@CLAUDE.local.md` line.
