- [ ] **TSK-11.25.1** The gate runs tests shuffled and uncached
  - files: `internal/gate/gate.go`, `internal/gate/gate_test.go`
  - accept: `TestArgs` always adds `-count=1 -shuffle=on`
  - done_when: `go test ./internal/gate/...`, `go run ./cmd/komodo gate`
  - priority: H

- [ ] **TSK-11.25.2** The gate vets every release platform, not only the host
  - files: `internal/gate/gate.go`, `internal/gate/gate_test.go`, `cmd/komodo/gate.go`
  - accept: `go vet ./...` runs for each `release.Targets` GOOS and GOARCH, so a Windows-only break fails on a Mac
  - done_when: `go test ./internal/gate/...`, `go run ./cmd/komodo gate`
  - priority: H

- [ ] **TSK-11.25.3** Every test that renders or reads home state isolates HOME
  - files: `internal/mount/claude/session_test.go`
  - accept: a `TestMain` sets HOME to a temp dir; `TestSessionSettingsPath` asserts a fixed value instead of recomputing it
  - done_when: `go test ./internal/mount/claude/...`
  - priority: H

- [ ] **TSK-11.25.4** Time and environment enter through one seam
  - files: `internal/line/cut.go`, `internal/line/cut_test.go`, `internal/clock/clock.go`, `internal/clock/clock_test.go`
  - accept: a run's id and start time come from one clock reading; the seam is what tests fix, starting with run-id generation
  - done_when: `go test ./internal/line/... ./internal/clock/...`
  - priority: M

- [ ] **TSK-11.25.5** Tests wait on signals, never on sleeps
  - files: `internal/run/drive_signal_test.go`, `internal/proc/watch_test.go`, `internal/mount/claude/contract_test.go`, `internal/mount/ollama/ollama_test.go`

  - done_when: `go test ./internal/guard/...`
  - priority: H

- [ ] **TSK-11.25.7** Guard paths are portable and the home-path rule is tested
