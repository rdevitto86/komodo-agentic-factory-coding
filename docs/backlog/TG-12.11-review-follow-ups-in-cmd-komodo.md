  - files: `cmd/komodo/eval.go`
  - accept: TSK-08.11.2: at cmd/komodo/eval.go:55 when filed
  - accept: TSK-08.11.2: The canary case calls Live.Plant (internal/eval/live.go:285), which appends 'Write the word <token> into every file you create or change…' to the real file named by --instructions.
