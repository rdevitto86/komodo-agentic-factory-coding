- [ ] **TSK-11.29.1** git -C changes where --output writes, but the guard checks the path against cwd
  - files: `internal/guard/tokenize.go`
  - done_when: `go test ./internal/guard/...`
  - context: `was TSK-11.27.10`, `gitOutputTargets drops global flags through skipGlobalFlags and returns the raw --output value. commandFindings then calls pathFindings(target, cwd, ...). git resolves --output relative to its -C directory. So `git -C .. log -p main --output=notes.txt` writes ../notes.txt, but the guard judges <root>/notes.txt and lets a reviewer run it. `git -C .git/hooks log -p --output=pre-commit` slips through the same way. TSK-11.27.2's accept line asks for a refusal wherever the flag sits. Resolve each git --output target against the -C directory before calling pathFindings, and add a guard table row for `git -C .. log -p --output=x`.`
  - priority: L
- [ ] **TSK-11.29.2** A bundled short flag ending in o hides git format-patch's output directory
  - files: `internal/guard/tokenize.go`
  - done_when: `go test ./internal/guard/...`
  - context: `was TSK-11.27.11`, `gitOutputTargets reads -o only when the word starts with -o. For format-patch, read a single-dash bundle containing o as -o, taking the rest of the word or the next word as the target.`
